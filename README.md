# LinuxDoReader

一个专为 `linux.do` 论坛设计的 Chrome 自动化增强扩展，旨在提供更拟人化、智能化的自动阅读与点赞体验。

## 核心功能

### 1. 拟人化阅读引擎
*   **非线性随机滚动**：模拟真实用户，在步长和延迟之间随机波动。
*   **模拟阅读停顿**：浏览时随机进入“深度阅读”模式，暂停数秒，极大提高行为仿真度。
*   **智能触底检测**：兼容 Discourse 论坛“懒加载”机制，确保读完新加载内容后再跳转。

### 2. 高级点赞策略
*   **跟风点赞逻辑**：仅在帖子/回复已有一定点赞基础时触发点赞，符合真实社交趋势。
*   **点赞拟人化**：随机观察期与概率触发机制，避免机械化逢贴必赞。
*   **自动冷却保护**：检测到论坛“点赞上限”时自动进入 24 小时静默期，智能保护账号安全。

### 3. 全自动导航循环
*   **全列表随机选帖**：从列表随机挑选话题，提高刷帖的随机性和覆盖面。
*   **无感接管逻辑**：读完或离开话题页回到列表时，自动启动下一轮选帖跳转，实现全自动挂机。
*   **优先清理未读**：自动导航优先返回未读（Unseen）列表，高效提升论坛活跃。

### 4. 交互与便捷控制
*   **即时生效**：开关切换立即生效，无需刷新页面。
*   **页面悬浮面板**：页面内直观控制开关，支持一键切换。
*   **状态同步**：Popup 页面与悬浮面板状态实时双向同步。
*   **任务时长控制**：支持设定自动任务的运行时长，超时自动停止。

### 5. 可配置参数说明
在扩展的 Popup 界面中，你可以动态调整以下参数：

**通用设置 (General)**
*   `Task Duration`: 任务持续时间（分钟）。设置为 `0` 表示无限循环，直到手动关闭。
*   `Refresh Delay`: 当列表页无内容时的刷新间隔（毫秒）。

**滚动行为 (Scroll Behavior)**
*   `Step (Min-Max)`: 单次滚动的像素距离范围。
*   `Delay (Min-Max)`: 两次滚动动作之间的时间间隔范围（毫秒）。
*   `Pause Prob.`: 模拟阅读停顿的概率（0-1）。
*   `Pause Max`: 停顿的最大时长（毫秒）。

**点赞行为 (Like Behavior)**
*   `Min Likes`: 跟风阈值。只有当帖子已有赞数大于此值时才考虑点赞。
*   `Probability`: 点赞触发概率（0-1）。
*   `Delay (Min-Max)`: 点赞动作的延迟时间范围（毫秒）。

## 安装步骤

1. 下载项目代码并解压。
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`（扩展程序）。
3. 开启右上角的**“开发者模式”**。
4. 点击**“加载已解压的扩展程序”**。
5. 选择解压后的文件夹即可完成安装。
