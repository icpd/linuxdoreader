# LinuxDoReader

一款专为 `linux.do` 论坛设计的 Chrome 浏览器扩展。通过阅读节奏控制与智能点赞逻辑，帮助用户自动浏览帖子，保持论坛活跃。

## 🌟 核心特性

- **阅读节奏控制**：从论坛首页开始，按分段滚动、随机停顿、少量回看和每帖随机阅读预算来浏览帖子，并兼容 Discourse 懒加载机制。
- **智能点赞**：基于社交证明（热度）的点赞逻辑，支持概率触发与冷却保护，避免因点赞过快触发论坛限制。
- **任务时长控制**：支持设定运行分钟数，超时自动停止。


## 🚀 安装与使用

1. 下载并解压本项目。
2. 打开 Chrome `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目根目录。
5. 在 `linux.do` 页面，通过点击插件图标或页面右下角的悬浮面板进行控制。

## ⚙️ 参数说明

点击扩展图标即可进入设置面板，调整下列参数以自定义浏览行为：

### 通用设置 (General Settings)
*   **Duration (m)**: 任务运行最大时长（分钟）。设置为 0 表示不限制时长。
*   **Nav Delay (ms)**: 在论坛首页或列表页跳转到帖子详情页前的等待时间（毫秒）。
*   **Ref Delay (ms)**: 若当前列表页无合适帖子，刷新页面前的等待时间（毫秒）。

### 滚动行为 (Scroll Behavior)
*   **Step Min/Max (px)**: 每段滚动操作滑动的最小/最大像素距离。
*   **Delay Min/Max (ms)**: 两段滚动操作之间的随机间隔时间（毫秒）。
*   **Pause Prob.**: 滚动过程中较长阅读停顿的概率（0-1，例如 0.22 表示 22% 概率）。
*   **Pause Min/Max (ms)**: 触发停顿时的持续时间范围（毫秒）。

系统会为每个帖子随机生成阅读进度与阅读时长预算，达到预算后可能返回论坛首页选择下一帖；不会要求每个帖子都刷到底。

### 点赞策略 (Like Behavior)
*   **Min Likes**: “跟风点赞”阈值。只有当帖子已有赞数大于此值时，才会考虑点赞。
*   **Prob. (0-1)**: 满足条件后实际执行点赞的概率（例如 0.8 表示 80%）。
*   **Cooldown (h)**: 触发论坛点赞上限后的自动冷却时间（小时）。
*   **Delay Min/Max (ms)**: 决定点赞后，执行点击动作前的随机延迟（毫秒）。

## ⚠️ 注意事项

*   本工具仅用于学习与交流，请合理控制使用频率。
