# LinuxDoReader 行为节奏优化方案

## 目标

将自动阅读从固定循环滚动调整为阅读节奏驱动：进入帖子后先停留，按内容分段滚动，段落间暂停，偶尔小幅回看；每个帖子生成独立的随机阅读预算，达到本帖预算后不强制刷到底。点赞只在帖子可见并停留过后触发。起始页和回退页统一使用论坛首页 `https://linux.do/`。

本方案不做规避检测、不伪造可信真人事件、不绕过论坛限制。

## 实现范围

- `content.js`：调整导航入口、滚动节奏、随机阅读预算、触底或预算结束后回首页、点赞前的可见性和停留校验。
- `background.js`、`popup/popup.js`：同步更慢的默认参数。
- `README.md`：更新首页起始和阅读节奏说明。

## 默认行为

- 默认起始页：`https://linux.do/`。
- 进入帖子前等待：`5000ms`。
- 分段滚动距离：`320-900px`。
- 普通段落停顿：`800-2600ms`。
- 长停顿概率：`0.22`。
- 长停顿时间：`3500-12000ms`。
- 点赞延迟：`15000-45000ms`。
- 每帖随机阅读模式：skim / normal / deep。
- 每帖预算同时包含随机阅读进度和随机阅读时长，长帖不一定比短帖停留更久。

## 验证点

- 开启 Auto-Read 后，非帖子页默认进入论坛首页。
- 首页能选择主题进入阅读。
- 主题页滚动表现为分段滚动和阅读停顿。
- 到达底部或达到本帖随机阅读预算后回到论坛首页。
- Auto-Like 只在当前帖子可见且停留过后尝试点赞。
